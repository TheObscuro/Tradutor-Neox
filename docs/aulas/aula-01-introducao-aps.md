# Aula 1 — Introdução à Análise e Projeto de Sistemas (resumo)

## Conceitos

- **Análise** → *o quê* o sistema precisa fazer, quem vai usá-lo e quais regras deve respeitar.
- **Projeto (design)** → *como* será construído: classes, telas, banco de dados, arquitetura.
- Pular essas etapas gera sistemas difíceis de manter, com retrabalho e que não atendem o cliente.

## As quatro etapas do desenvolvimento de software

| Etapa | Descrição |
| --- | --- |
| 1. Especificação | Define o que o sistema deve fazer e sob quais restrições (prazo, tecnologia, orçamento, segurança). |
| 2. Desenvolvimento | Projeto e implementação: arquitetura, classes, telas, código. |
| 3. Validação | Verifica se o que foi construído atende ao especificado (testes, revisão com o cliente). |
| 4. Evolução | Em produção, surgem novos requisitos, correções e adaptações. Ciclo contínuo. |
